## Management layer for decisions

- **Four pinned skills:** edit `modules/agent-skills.nix:18` manifest. `modules/agent-skills-sync.sh` manages only Nix-store symlinks: it updates pins and removes Nix-store links removed from the manifest on activation. Directly deleting a managed link is temporary; it returns on activation. Local directories override a pinned link, intentionally.
- **Five local skills:** edit/remove the tracked directories in `home/hatim/agents/skills/`. Fix aliases to resolve the shared skill independently of current working directory if retaining them.
- **Thirteen synced skills:** bucket is ignored by `home/hatim/agents/skills/.gitignore`. It is an Anthropic sync cache with a manifest and round marker. These are **not currently exposed to pi**, so deleting them provides no pi context saving. If cleaning the shared cache is desired, change its syncing source rather than assuming cached-file deletion persists. This audit did not find the syncing producer in the Nix/shared-skill modules; do not infer it is Nix-managed.
- **pi exposure:** no `home/hatim/pi/skills` directory exists, and pi settings contain packages but no explicit skills key. Runtime shows the nine top-level skills load; the nested bucket does not. Coordinate active exclusions with the separate pi loader audit.
